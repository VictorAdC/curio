# Pages Specs

This folder documents each application page.

Each page spec should describe:

- the page purpose;
- the target user;
- the main actions available on the page;
- required UI sections;
- state dependencies;
- persistence needs;
- audio or YouTube integration needs;
- navigation entry and exit points;
- validation and edge cases.

## Suggested Convention

- One file per page.
- Use stable names such as `home.md`, `practice-session.md`, or `library.md`.
- Focus on behavior and requirements, not implementation details.
