# System Design Specs

This folder documents how the whole system is shaped at a higher level.

Even for a static app, system design is useful to describe:

- the main subsystems;
- how data flows through the app;
- how playback, persistence, and UI interact;
- where future backend integration could fit;
- constraints and scalability assumptions.
