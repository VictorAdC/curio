# Feature Specs

This folder documents feature-level requirements that are not tied to a single page.

Examples:

- practice timer;
- loop and repeat tools;
- pitch or tempo controls;
- study playlists;
- session history;
- saved exercises.

Planning and roadmap-style feature guidance may also live here when it is meant to stay as permanent project documentation.

Current planning document:

- [next-steps.md](./next-steps.md)

Each feature spec should describe:

- goal;
- user value;
- dependencies;
- state model;
- persistence model;
- page touchpoints;
- success criteria.
