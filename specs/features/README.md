# Feature Specs

This folder documents feature-level requirements that are not tied to a single page.

Examples:

- practice timer;
- loop and repeat tools;
- pitch or tempo controls;
- study playlists;
- session history;
- saved exercises.

Each feature spec should describe:

- goal;
- user value;
- dependencies;
- state model;
- persistence model;
- page touchpoints;
- success criteria.
