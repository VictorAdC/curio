# Testing Specs

This folder documents the testing strategy and quality expectations.

It should define:

- what needs unit testing;
- what needs integration testing;
- critical user flows to validate;
- browser behavior that needs manual verification;
- audio-related testing constraints;
- persistence-related test cases.
